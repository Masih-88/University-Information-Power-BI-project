# 🎓 University Information Power BI Project

This Power BI project analyzes **university departments, student performance, applicants, and courses** to uncover insights across different academic areas.  

## 📊 Overview
The goal of this project is to transform raw, messy CSV and Excel data into a clean, interactive Power BI dashboard that helps visualize key university metrics and performance indicators.

## 🧰 Tools & Technologies
- **SQL Server** – for data storage and querying  
- **Power Query** – for data cleaning and transformation  
- **Power BI Desktop** – for building interactive reports and dashboards  
- **DAX (Data Analysis Expressions)** – advanced calculations and dynamic measures  

## ⚙️ Process
1. **Data Collection:** Imported multiple raw CSV and Excel files containing department, student, and course data.  
2. **Data Cleaning:** Used Power Query to handle missing values, remove duplicates, and standardize data formats.  
3. **Data Modeling:** Created relationships between applicants, students, and course tables in Power BI.  
4. **DAX Calculations:** Applied complex DAX formulas to calculate key metrics such as student success rate, average GPA, and course enrollment trends.  
5. **Visualization:** Designed a Power BI dashboard for interactive exploration of department performance, student outcomes, and application statistics.

## 📈 Key Insights
- Identified top-performing departments based on student performance metrics.  
- Analyzed course demand and enrollment patterns across departments.  
- Tracked applicant conversion rates and student progression.
